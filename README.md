    # AgendaCribe

Proyecto de aplicacion movil para gestion medica

#OBJETIVO DEL PROYECTO
Desarrollar una aplicacion movil intuitiva dirigida a profesionales de la salud, el programa debera permitir administrar citas, redactar notas de sesion, llevar el control de expedientes de pacientes y revisar notificaciones desde el celular, todo esto con el fin de mejorar la organizacion y productividad en la practica clinica diaria.

Buscamos que el programa sea facil de usar desde cualquier dispositivo movil, asegurando que la informacion del paciente y la agenda esten siempre accesibles y actualizadas mediante una navegacion rapida por pestañas.

#PASOS PARA INSTALAR Y EJECUTAR EL PROGRAMA

1. Instalar Node.js.
Descargar e instalar Node.js en su version 18 o superior.
2. Obtener el proyecto.
Tener la carpeta con los archivos del proyecto (agenda_cribe) guardada en tu computadora.
3. Abrir la consola.
Abrir la aplicacion con el "Simbolo de windows" y luego escribir "cmd" o usar la terminal de tu sistema.
4. Ir a la carpeta del proyecto.
Usar el comando cd seguido de la ruta de la carpeta del proyecto.
5. Instalar las dependencias.
Escribir el comando npm install y presionar Enter para que se descarguen todas las configuraciones necesarias.
6. Ejecutar el programa.
Escribir npx expo start para levantar el servidor local del proyecto.
7. Abrir la aplicacion en el celular.
Descargar la aplicacion Expo Go en tu dispositivo movil y escanear el codigo QR que aparece en la consola para empezar a usar la agenda.
